# TyraCraft browser assets

Versioned, independently cacheable browser assets for the TyraCraft PlayStation 2
homebrew integration on AI Game Portal.

This repository does not contain a Sony BIOS. The game runs through Play!'s HLE
BIOS. Large release artifacts are attached to GitHub Releases; the `portal/`
directory is the lightweight page imported by the portal.

See `ASSET-NOTICES.md` and `PATCHES.md` for licensing and compatibility details.
